# Audit photographique MycoMap — 2026-11-16

## Objectif
Chaque fiche doit proposer **au moins trois vues morphologiquement complémentaires** : (1) chapeau vu du dessus, (2) pied entier et base si possible, (3) hyménophore vu du dessous (lamelles, pores, aiguillons, plis, surface fertile). Pour les espèces sans chapeau/pied/lamelles classiques (pézizes, polypores, morilles...), adapter les vues à leur morphologie. Les trois vues doivent être **identifiées et vérifiées** ; trois photos de chapeau ne satisfont pas le critère.

## Contrôles à réaliser pour chaque fichier
- URL accessible, pas de redirection cassée ni d'image absente.
- Identification de l'espèce corroborée par la page source ; mentionner les synonymes et les groupes d'espèces.
- Auteur, licence et attribution exacts, avec lien vers la page source.
- Vue réellement représentée (dessus, pied/base, dessous) ; éviter les vues redondantes.
- En priorité, vérifier les espèces toxiques et leurs sosies.

## Note de méthode
Ce fichier est un **inventaire automatisé des références dans le code**, pas une validation des photographies sur le terrain ou des liens HTTP. Ne pas annoncer les photos comme vérifiées sans contrôle effectif.
