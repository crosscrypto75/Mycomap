# MycoMap 🍄

Carte interactive de prospection autour de Blain.

## V1
- Fond satellite IGN, avec repli OpenStreetMap en cas d'échec.
- Couche cadastrale IGN à partir du zoom 14.
- Repères indicatifs de secteurs forestiers.
- Géolocalisation et observations enregistrées uniquement dans le navigateur.
- Export et import JSON des observations.

## Activer le site
Dans Settings → Pages : Deploy from a branch → main → /(root) → Save.

## Limites
La carte nécessite Internet. Les secteurs sont approximatifs, non exhaustifs et ne prouvent pas un droit d'accès ou de cueillette. Les observations locales peuvent être perdues si les données Safari sont effacées : exporter régulièrement.
